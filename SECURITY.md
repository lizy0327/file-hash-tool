# 安全策略 / Security Policy

## 范围 / Scope

这是一个本地文件校验工具。程序设计为在本机读取文件并计算校验值，不需要上传文件或连接远程服务。

This is a local file verification tool. It is designed to read files and calculate hashes on the local machine without uploading files or connecting to a remote service.

## 报告问题 / Reporting a vulnerability

请不要在公开 Issue 中发布密码、私钥、真实内网地址、个人文件路径或完整敏感日志。请先通过仓库维护者提供的私密渠道报告；如果仓库已启用 GitHub Private Vulnerability Reporting，请使用该功能。

Do not publish passwords, private keys, real internal addresses, personal file paths, or complete sensitive logs in a public issue. Contact the maintainers through a private channel first; if GitHub Private Vulnerability Reporting is enabled, use that feature.

报告时请提供复现步骤、受影响平台、版本和经过脱敏的日志。/ Include reproduction steps, affected platform, version, and redacted logs in a report.

## 安全边界 / Security boundaries

复制结果可能包含文件绝对路径；分享前请检查剪贴板内容。/ Copied results may contain absolute file paths; review clipboard content before sharing.
